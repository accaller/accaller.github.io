恭喜！你现在看到的这篇文章，就是一篇攻略的标准样子。发布新攻略只需两步：

## 第一步：新建 Markdown 文件

在 `src/content/guides/` 文件夹里新建一个 `.md` 文件（**文件名建议用英文或拼音**，它会出现在网址里，比如 `genshin-beginner.md` → `/guides/genshin-beginner/`）。

文件开头必须写下面这段「信息头」（frontmatter），格式如下：

```md
---
title: 攻略标题（必填）
description: 一句话摘要，显示在列表卡片和搜索引擎里（必填）
game: 游戏名，如 塞尔达传说（必填，用于自动分组）
date: 2026-08-15（必填，发布日期）
tags: [新手, BOSS]（可选，标签）
cover: /images/cover.jpg（可选，封面图）
pinned: false（可选，true 时在列表置顶）
---
```

## 第二步：写正文并上传

信息头下面直接用 Markdown 写正文，然后推送到 GitHub（或在 GitHub 网页上直接新建/编辑这个文件）。推送后 **1-2 分钟**内自动构建上线。

> 💡 不用本地装任何软件：在 GitHub 仓库页面进入 `src/content/guides/` → 点 `Add file` → `Create new file` → 写完点 `Commit changes`，网站就会自动更新。

## 正文常用写法速查

### 图片

先把图片上传到 `public/images/`，然后一行引用：

```md
![图片描述](/images/my-screenshot.jpg)
```

### 表格（装备/配装/数值对比）

| 阶段 | 推荐武器 | 替代选择 |
| ---- | -------- | -------- |
| 前期 | 铁剑 | 木棍 |
| 中期 | 骑士剑 | 王家剑 |
| 后期 | 大师剑 | —— |

### 提示块（注意事项）

> ⚠️ 注意：用 `>` 开头的引用段落会渲染成这种高亮提示框，适合放避坑提醒。

### 列表和标题

- `## 二级标题` 会自动带上分隔线
- `### 三级标题` 用于小节
- 无序列表用 `-`，有序列表用 `1.` `2.`

写完这篇，你已经掌握本站的全部更新流程了 🎉
