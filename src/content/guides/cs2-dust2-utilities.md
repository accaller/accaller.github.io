## A 区道具

### A 门烟雾（CT 防守位）

站 A 平台边缘，准星对齐远处山体轮廓线，左键满力投掷。

| 道具 | 站位 | 准星参照 | 投掷方式 |
| ---- | ---- | -------- | -------- |
| A 门烟 | A 平台 | 山体缺口上沿 | 左键满力 |
| 警家烟 | A 小道口 | 电线杆顶部 | 跳投 |
| A 火 | 斜坡道 | 木箱右角 | 左键短抛 |

### 常用组合

1. **快攻 A**：A 门烟 + 警家烟 + 斜坡火，三道具 15 秒内铺完
2. **假打转 B**：A 门烟丢出后听 CT 回防脚步，转点打 B

> 💡 跳投绑定建议：`bind v "+jump;-attack;-attack2;-jump"`，按住 V 即稳定跳投。

## B 区道具

### B 区一线烟（匪家出发）

出生后直走至碉堡右侧，准星对齐天空横梁，跳投双烟封 B 门口与窗口。

| 道具 | 效果 | 备注 |
| ---- | ---- | ---- |
| 一线烟 ×2 | 封死 B 门视线 | 需双人同步 |
| B 门口火 | 阻止rush | 落点在门框内一步 |
| 闪光 | 过点掩护 | 高抛过门顶 |

> ⚠️ 一线烟两个烟必须同时落地，否则 CT 能从缝隙看到过点位置，练跑图时先和队友对表。

## 对枪小技巧

- **急停**：松开方向键的瞬间轻点反向键，准星回正再开枪
- **预瞄**：把准星始终放在敌人可能出现的头部高度，过点不低头
- **压枪**：AK 前 7 发基本直线，第 8 发开始向左上拉，中距离只打前 7 发
