## 复制人选择

开局三人的技能倾向，建议 1 研究 + 1 挖掘/建造 + 1 杂务：

| 倾向 | 优先技能 | 理由 |
| ---- | -------- | ---- |
| 研究 | 学习加速 | 尽早解锁关键科技 |
| 挖掘 | 硬质挖掘 | 开拓空间与找水 |
| 杂务 | 勤杂 | 前期脚手架基建全靠他 |

> ⚠️ 负面特性避开「 bladder -9 」这类高频打断型，前期效率损失比想象中大。

## 前 10 周期目标

按优先级依次完成，别乱序：

1. **厕所循环**：户外厕所 + 洗手盆，先不碰管道
2. **氧气**：制氧机 ×2（藻类），放基地中心
3. **电力**：人力发电机 + 小电池，研究站旁
4. **食物**：米虱木种植箱 ×6，配一张餐桌
5. **科研**：优先点出「新农业」和「高级过滤」

> 💡 第 5 周期左右会出现第一波压力，确保宿舍有 4 格高的封闭空间 + 床，压力值能压住。

## 电力规划（10-20 周期）

```
人力发电机 ─→ 小电池 ─→ 制氧机 / 研究站
                    └→ 抽气泵（备用）
```

- 电池组**远离卧室**（噪音 -10% 士气）
- 电线走地板层，别穿农业区（装饰度惩罚）
- 煤电先不急，藻类制氧撑到 20 周期没问题

## 常见死法与对策

| 死法 | 原因 | 对策 |
| ---- | ---- | ---- |
| 氧气断供 | 藻类耗尽没转型 | 15 周期前开始点电解水科技 |
| 食物中毒 | 生吃米虱 + 洗手盆没电 | 食物全煮熟，洗手盆优先供电 |
| 压力崩盘 | 睡大厅 + 没娱乐 | 封闭卧室 + 跑步机/背摔台 |
| 热死 | 基地深处设备散热 | 制氧区与居住区隔 3 格以上 |

---

按这个顺序走，20 周期时你应该有：稳定氧气、熟食供应、两台研究站、以及一个不崩心态的复制人团队。之后的转型（电解制氧、煤炭链、农牧）见后续篇章。
